# 营销资料平台一期 · 开发验收记录

验证日期：2026-11-24。范围为本仓库生成的 Vue 前端、Worker 服务、隔离的演示身份与受控文件服务。正式 Partner Center 的接口按约定模拟，未使用锐捷生产账号、资料或凭据。

| 项目 | 验证结果 |
|---|---|
| 可见范围 | 两个浏览器空间的需求互不可见。伙伴不能取得内部附件、仅预览附件的原件或维护接口；不同签约关系的 BG 与区域无法组合授权。 |
| 上传时设置附件权限 | 已验证批次继承、独立设置、超范围上传拒绝、审核前不可见，以及审核后按附件限制预览和下载。 |
| 签约国家与伙伴类型 | 验证编辑页选择国家、添加授权组、历史规则兼容，以及下载和附件范围校验。模拟门户会话测试泰国经销商仅可预览、越南集成商可下载；交叉签约、已停用签约和缺少国家均不能访问受限原件。审核前旧版可用，审核后资料库、收藏、场景包和直链同步按新规则判断。 |
| 提交到交付 | 伙伴提交需求、编辑认领和上传、独立审核、发布、一次交付通知、领取文件和下架后的失效均通过。要求对客外发时，只读或内部版本不能交付。 |
| 资料维护 | 自定义资料类型与专属字段可发布，审核期间旧版继续服务。新版本生效后收藏与清单指向新版，到期提醒可标记已读。 |
| 证据、纠错与场景包 | 一线可从详情提交纠错并带到原负责人。场景包不能自审且隐藏受限引用；证据撤回后，依赖它的资料卡片和下载入口同时失效。 |
| 文件兼容性 | 中文 PDF、DOCX、PPTX、UTF-8 文本均能取得文字预览；PNG、JPEG 生成独立图片预览。试点不承诺还原 Office 排版。 |
| 站内消息与门户适配 | 页面在获得焦点或轮询时获取新消息。消息适配器在测试中模拟失败、重试与成功，使用相同幂等键。模拟正式账号停用及附件扫描拒绝，后端正确拦截。 |
| 前端与运行时 | 发布包在 DOM 测试中成功渲染资料中心、附件详情、需求表单和编辑页。在 workerd + 本地 R2 模拟存储中另行验证首页、会话、持久写入、需求交付、通知与 PDF 下载。 |

运行 `npm ci && npm test` 可复验 14 项自动化测试，运行 `npm run test:worker` 可复验 Worker 集成链路。前端挂载测试不等同于手机真机视觉验收。

**正式导入前的外部依赖。** 对接方需提供 PC 集成环境、员工与伙伴测试账号、会话及签约关系查询、扫描和消息服务的地址与协议。届时验证真实账号停用时效、正式消息到达及目标设备的交互表现。私有 Sites 体验版使用示例身份，与正式业务数据隔离。
